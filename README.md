## Hi, I'm Peri 👋

I build mobile apps — mostly Android, in Kotlin and Compose, and lately iOS too, in Swift and SwiftUI.

For eight years I worked on marketplaces in Istanbul: [sahibinden.com](https://www.sahibinden.com), [Trendyol](https://www.trendyol.com) and [arabam.com](https://www.arabam.com). The kind of apps where a bad release is noticed by a few million people before lunch. I led a Java-to-Kotlin migration, spent a year as the only Android developer on an app used by millions, and built real-time auction features from scratch.

Since moving to Frankfurt I've been building my own things.

**[Noor – Muslim Companion](https://play.google.com/store/apps/details?id=com.nextdaymobilestudio.ramadancountdown)** is a daily companion app: prayer times with a live countdown, Qibla from the phone's sensors, nearby mosques, a Zakat calculator, and salawat rooms where people keep count together. I wrote both clients myself — Android in Compose, iOS in SwiftUI — on one Firebase backend. It has passed 5,000 installs and sits at 4.5 stars, which still surprises me a little.
[Google Play](https://play.google.com/store/apps/details?id=com.nextdaymobilestudio.ramadancountdown) · [App Store](https://apps.apple.com/app/id6758920980) · [noormuslimapp.com](https://noormuslimapp.com)

**[Leben in Deutschland](https://github.com/perierol/leben-in-deutschland)** prepares people for the German integration test. 460 official questions in 21 languages, right-to-left for Arabic, Persian and Pashto, the whole thing working offline. I moved here two years ago, so I know what it's like to arrive somewhere and have to learn a country from a question bank.
[Repository](https://github.com/perierol/leben-in-deutschland)

I started out writing test automation in Appium, and it stuck. My own projects still ship with unit tests, UI tests and CI, even when nobody is making me.

I also care about the parts users never name: how a list scrolls, what happens when the network drops mid-sync, whether the app still works on a train with no signal.

**Tools:** Kotlin · Jetpack Compose · Coroutines & Flow · Room · Hilt · Swift · SwiftUI · Firebase · GitHub Actions · Compose UI tests · Appium
